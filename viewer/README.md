# 개인용 새농 화면

`saenong-dashboard.zip`을 다운로드해 압축을 풀고 `새농.html`을 Chrome 또는 Edge에서 엽니다.
별도로 전달받은 열기 암호를 입력하면 월 선택·차트·표를 볼 수 있습니다.
설치나 환경 게시가 필요하지 않으며, 인터넷 연결을 끊어도 파일 안의 자료를 볼 수 있습니다.

이것은 화면에 표시된 시각에 저장한 자료입니다. 자동으로 갱신되지 않습니다.
암호를 잃어버렸다면 저장소에 인증 정보나 매출 원본을 올리지 말고 파일을 만든 사람에게 문의하세요.

이 폴더에는 암호화된 전달용 파일만 보관합니다. 평문 HTML, 원본 보고서,
ATPOS 계정 정보와 열기 암호는 포함하지 않습니다.
