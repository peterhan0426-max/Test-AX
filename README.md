# 새농 · 매출과 이익

매장별 월 매출·매출총이익·마진·목표 달성률, 일별/월별 매출 추이,
프로모션 할인을 보여주는 조회 전용 웹 애플리케이션입니다.

**개발 상태:** 실제 제공된 ATPOS 파일 네 종류의 합계 대조와 가져오기,
웹 화면·API·모바일 표시 검증을 수행했습니다.
로그인 뒤 무인 조회/다운로드, 정기 수집, 원격 서버 전송·공개 배포는 아직 완료되지 않았습니다.
Windows 실사용 확인이나 GitHub Actions 결과를 검증 완료로 간주하지 않습니다.
사용자에게 초안 설치·테스트를 요청하는 배포 단계가 아닙니다.

## 계산 기준

- 총매출 = 순매출 + **할인액**. ATPOS 손익표의 `총할인`은 조정·폐기 영향이 섞여 있어 사용하지 않습니다.
- 매출원가 = 기초재고 + 순매입 − 기말재고
- 매출총이익 = 총매출 − 매출원가
- 마진율 = 매출총이익 ÷ 총매출 × 100. 총매출 0원일 때는 계산하지 않습니다.
- 매출 목표: 전년 동월 대비 가락·야탑 5%, 동천 10% 성장.
  1·2월 및 9·10월은 각각 전년 두 달 총매출 평균에 성장률을 적용합니다.
  기준 월의 자료가 없거나 월 전체 자료가 아니면 목표는 미계산으로 둡니다.
- 마진 목표: 가락·야탑 18.5%, 동천 16.5%.
- 월별 손익은 선택 월의 자료이며 당월은 MTD 잠정값입니다. YTD 차액을 계산하지 않습니다.
- 할인·취소·반품·부가세·폐기는 원본에 반영된 것으로 보고 추가 조정하지 않습니다.
- 프로모션 요약의 고객별 할인을 집계하고 품목별 할인과 대조합니다. 상세 보고서를 추가 합산하지 않습니다.
- 음수는 보존하며, 자료 누락은 0원으로 바꾸지 않습니다.

## 자료 처리

`.xls` 확장자지만 실제로는 CP949 HTML 표인 ATPOS 내보내기 형식을 읽습니다.
행/열 병합을 해석하고, 상세 행과 파일 전체 합계를 대조한 뒤에만 반영합니다.
잘못된 보고서나 로그인 화면은 집계하지 않습니다.
동일 조회 월·매장·보고서의 정정 파일은 기존 활성 자료를 대체하고 이력과 원본은 보존합니다.
더 오래된 기준일의 파일로 최신 집계를 덮어쓰지 않습니다.
프로모션 상세는 실제 매출일자로 조회 월과 기준일을 필터링합니다.

원본에 대분류 없이 소분류만 있으므로 임의로 4개 카테고리를 추측하지 않습니다.
데이터 폴더의 `categories.json`에 확정된 ATPOS 분류 연결을 넣으면 적용됩니다.
형식은 `{"확정된 소분류명": "정육/냉장"}`이며 허용값은 정육/냉장, 과일/채소, 상온/냉동, 기타입니다.
연결 전 항목은 미분류로 표시합니다.

## 개발자가 실행하는 방법

Python 3.11 이상이 필요합니다. 웹 앱과 파일 집계는 Python 기본 라이브러리만 사용합니다.
저장 폴더는 코드 체크아웃 밖의 비공개 경로로 지정합니다.

```sh
python -m saenong FILE.xls --data-dir /private/saenong --store 가락 --period 2026-10 --as-of 2026-10-21
python -m saenong.server --data-dir /private/saenong --port 8000
```

매장과 조회 월이 파일 자체에 없는 보고서는 수집 시 명확히 기록해야 합니다.
입력된 조건은 원본 화면을 검증한 증거로 간주하지 않습니다.
`--as-of`는 실제 자료 조회 종료일이며 실행 날짜를 무조건 대입하지 않습니다.

공개 배포는 운영용 HTTPS 리버스 프록시와 Python 서비스 관리자를 사용해야 합니다.
Python 개발용 HTTP 서버를 그대로 인터넷에 노출한 상태를 운영 배포 완료로 간주하지 않습니다.
API와 정적 화면만 서비스하며 원본, SQLite, 세션 파일은 HTTP로 제공하지 않습니다.
분석 저장 데이터에는 고객명·고객번호·카드번호·영수증번호를 넣지 않습니다.
원본 파일에는 개인정보가 있으므로 별도 접근 통제와 백업이 필요합니다.

## 개발용 Windows 수집 도구

`START.cmd`는 필요 패키지·전용 Chromium을 설치하고 로그인 브라우저를 엽니다.
Python이 없으면 공식 설치 페이지를 엽니다. Python 3.11 이상과 Python launcher가 필요합니다.
사용자가 조회한 후 콘솔에서 보고서·매장·기간을 지정하고 엑셀 버튼을 누르면
원본을 보관하고 단일 매장·단일 월 자료를 검증해 반영합니다.
로그인 세션은 PC에 보관하며 사이트가 만료시키면 재로그인이 필요합니다.
`DASHBOARD.cmd`는 같은 PC에 보관된 자료의 조회 화면을 엽니다.
기본 데이터 위치: `%LOCALAPPDATA%\SaenongCollector`.
이 도구는 무인 수집 완성본이 아닙니다.

## 실제 사이트 인증 검증

환경 설정에 `ATPOS_ID`, `ATPOS_PASSWORD`의 비밀 인증 연결을 입력합니다.
값을 채팅, 코드 또는 `.env` 파일에 넣지 않습니다. 프록시 인증 연결은
허용 목적지 `www2.atpos.co.kr`에서 사용하며, 로그인 정보는 출력하지 않습니다.

```sh
python -m collector.authenticate --data-dir /private/saenong --executable /path/to/chromium
```

이 명령은 실제 로그아웃 UI를 확인해야 성공으로 판정하며 비공개 세션을 저장합니다.
실제 자격 증명으로는 아직 검증하지 않았습니다. 로그인 성공 뒤 보고서 화면 구조를
확인해야 자동 조회와 다운로드를 완성할 수 있습니다.

## 검증

```sh
python -m unittest discover -s tests -v
python -m pip install -r requirements.txt
python -m playwright install chromium
python tools/check_browser.py
```

실제 비공개 데이터로 화면을 검증할 때는 `--data-dir`을 추가합니다.
설치된 Chromium 사용 시 `--executable`로 경로를 지정할 수 있습니다.
GitHub Actions에는 Windows·Linux 자동 검사를 등록했습니다. 실행 결과는 별도 확인이 필요합니다.
매출 원본·실제 매출 데이터·계정·브라우저 세션은 GitHub에 포함하지 않습니다.
