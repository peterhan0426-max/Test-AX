# 새농 매출 수집기

Windows PC에서 사용자가 aTPOS에 직접 로그인하고 다운로드한 원본을
보관하는 첫 단계입니다. **무인 조회·다운로드, 서버 전송, 대시보드는 아직 구현하지 않았습니다.**

## Windows에서 실행

배포 ZIP은 압축을 푼 뒤 `START.cmd` 하나로 최초 설치와 실행을 진행합니다.
한국어 단계별 안내는 `처음읽기.txt`를 참고하세요.

1. GitHub의 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. 폴더 안의 **`START.cmd`**를 실행합니다. 최초 설치도 같은 파일에서 진행합니다.
   Python이 없으면 공식 다운로드 페이지가 열립니다. Python 3.11 이상과
   Python launcher를 설치한 뒤 `START.cmd`를 다시 실행하세요.
3. 열린 전용 Chromium 브라우저에서 aTPOS에 직접 로그인합니다.
4. 보고서 조회 후 콘솔에 종류, 매장, 기간을 입력하고 브라우저의 엑셀 버튼을 누릅니다.
5. 다음 보고서를 반복하거나 콘솔에 `q`를 입력해 종료합니다.

패키지와 Chromium 설치에는 인터넷 연결이 필요합니다.

월별 손익: 매출분석 → 매출분석 → 월별 매출이익표.
프로모션 요약/상세: 매출분석 → 프로모션의 해당 보고서.
월별 손익은 선택 월 기준이며 당월은 월 누적입니다.
프로모션 상세는 선택한 프로모션 전체 기간이 나올 수 있으므로 조회 요청 기간만으로
실제 자료 기간을 단정하지 않습니다. 현재 입력 조건은 사용자 기록이며 검증 완료를 뜻하지 않습니다.

## 보관

기본 위치는 `%LOCALAPPDATA%\SaenongCollector`입니다.
원본은 SHA-256별 한 파일로 보관하고 다운로드 이력은 SQLite에 별도로 기록합니다.
같은 파일을 다시 받아도 원본 파일이 중복 생성되지 않습니다.
이것은 다운로드 보관 기능이며 매출 중복 집계 방지나 정정 반영까지 구현한 것은 아닙니다.

이 폴더에는 로그인 세션과 고객 개인정보가 포함될 수 있습니다.
공개 웹 폴더, Git 또는 공유 드라이브에 올리지 마세요.
공개 분석용 데이터에는 고객명·고객번호·카드번호를 포함하지 않는 별도 변환이 필요합니다.
다른 위치는 `python -m collector.capture --data-dir 경로`로 지정합니다.

## 후속 연결

실제 PC에서 로그인 유지, 팝업, 파일 다운로드를 확인한 뒤 조회 자동화를 연결합니다.
작업 스케줄러 등록은 무인 수집이 검증된 다음 진행합니다.
서버 전송은 업로드 서버와 인증 방식이 정해진 뒤 구현합니다.
