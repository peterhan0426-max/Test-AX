새농 aTPOS 수집기 — Windows 실행 안내

1. ZIP 파일을 내려받고, 마우스 오른쪽 버튼 → 모두 압축 풀기를 누릅니다.
2. 압축을 푼 폴더의 START.cmd를 더블클릭합니다.
   첫 실행 시 필요한 패키지와 전용 브라우저를 자동 설치합니다.
   Python이 없으면 공식 다운로드 페이지가 열립니다.
   Python 3.11 이상을 설치할 때 Python launcher도 설치한 뒤 START.cmd를 다시 실행하세요.
3. 열린 전용 브라우저에서 aTPOS에 직접 로그인합니다.
4. 보고서를 조회한 다음 검은 창에서 보고서 종류, 매장, 시작일, 종료일을 입력합니다.
   날짜 형식: 2026-10-01
5. 브라우저의 엑셀 버튼을 누릅니다. 검은 창의 '원본 보관 완료'를 확인합니다.
6. 다른 보고서를 반복하거나 검은 창에 q를 입력해 종료합니다.

현재 가능한 것
- 직접 로그인한 브라우저에서 다운로드한 원본 보관
- 조회 조건 기록 및 같은 원본의 중복 파일 생성 방지
- 다음 실행 시 같은 전용 브라우저 프로필 사용
  (aTPOS가 로그인을 만료시키면 다시 로그인해야 합니다.)

아직 불가능한 것
- 매일 아침 무인 조회 및 엑셀 버튼 자동 클릭
- 서버 전송, 공개 대시보드, 매출 분석

이 초안은 실제 Windows/aTPOS에서 아직 검증하지 않았습니다.
무인 수집은 실제 로그인 후 페이지 구조를 확인한 다음 연결해야 합니다.

데이터 위치: %LOCALAPPDATA%\SaenongCollector
로그인 상태와 개인정보가 포함된 원본이 이 PC에 저장됩니다.
이 폴더는 공개하거나 공유하지 마세요. 비밀번호는 채팅으로 보내지 마세요.
오류가 나면 창을 닫지 말고 개인정보를 제외한 오류 문구만 알려주세요.
